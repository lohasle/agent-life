# Agent-Life Releases

本仓库用于发布 Agent-Life 桌面应用的版本更新和安装包。

## 版本检查

更新系统通过 GitHub Releases API 获取最新版本信息：

```
GET https://api.github.com/repos/lohasle/agent-life/releases/latest
```

## 下载

前往 [Releases](https://github.com/lohasle/agent-life/releases) 页面下载最新版本。

- **macOS**: `Agent-Life-{version}-mac.dmg`
- **Windows**: `Agent-Life-{version}-setup.exe`

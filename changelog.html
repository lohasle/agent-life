版本更新记录

这里记录 Agent OS 每个公开版本的实际变化。最新安装包见 GitHub Releases，平台与安装方式见 使用指南。

v0.2.92026-07-18
  • 任务 fallback 可用 — daemon 暂时不可用时，进程内 Runtime 仍可创建、编辑、删除和运行任务，不再提示“当前 Runtime Host 不支持任务调度”。
  • 周期调度互斥 — daemon 与 fallback 共用同一任务仓储，并在切换时严格交接调度器，避免丢任务或重复触发。
  • 桌面单实例 — 重复启动只聚焦已有窗口，不再让不同版本争抢同一个 daemon。
  • 完整发布验收 — 全量 350 项测试、41 项任务专项测试及安装包真机任务/Cron/单实例验证通过；19 个资产按源码 4a51dc8 重建并完成 SHA-256 核验。
v0.2.82026-07-18
  • Agent 任务看板 — 新增 Todo、In Progress、Review、Done 四列工作流，可创建任务、指定 Runtime Host / Agent CLI / 模型 / 工作区并跟踪执行状态。
  • 完整定时任务系统 — 支持一次性计划与 Cron、时区、错过执行策略、暂停 / 恢复 / 立即运行，并保留独立运行记录。
  • 后台可靠执行 — 计划由 Runtime daemon 持有；关闭桌面窗口后仍可运行，同一工作区自动串行，异常退出任务可恢复为中断状态。
  • 真实会话联动 — 任务执行创建真实 Agent 会话，成功后自动进入 Review，由用户人工确认 Done，也可从任务记录直接打开会话。
  • 重度历史库启动修复 — 存量原生会话回填改为后台执行，并将 transcript 元数据读取并发限制为 8，避免近千份 Claude / Pi 记录同时打开导致窗口迟迟不出现。
  • 远程节点制品修复 — 修复 macOS 节点包中 node-pty 辅助程序缺少执行权限导致的 posix_spawnp failed。
  • 最终制品刷新 — 19 个 Release 资产已按源码提交 0368955 完成最终重建与 SHA-256 核验，桌面首页同步展示最终构建状态。
  • 产品网站内容校准 — 官网按当前左侧导航重写产品能力，新增完整使用指南和 7 个桌面制品直达下载，并明确 CLI 登录、本地数据与模型服务边界。
v0.2.72026-07-16
  • 连续输入不丢失 — 活动回合运行期间新增持久 FIFO 队列，支持附件、取消和 daemon 重启恢复，回合结束后按顺序自动发送。
  • 会话滚动稳定 — 用户上滚阅读历史时不再被流式输出强制拉回底部；新增“跳到最新”，切换会话后恢复正确跟随状态。
  • Claude 输出可靠性 — 兼容 assistant 消息快照，重试过程不再被误判为空闲，并保留最终失败的真实原因。
  • Claude 附件修正 — 本地附件不再误用远端资源 --file，改由路径引用配合 Read 工具读取。
  • 远程节点协议升级 — runtime protocol 升级到 5，节点重连时同步刷新宿主版本与协议版本。
v0.2.62026-07-03
  • 会话内 Ctrl/Cmd+F 搜索 — 活跃会话与历史详情中原地高亮所有匹配、当前匹配深色聚焦；Enter 下一个、Shift+Enter 上一个、Esc 关闭，带 N/M 计数。
  • 思考 / 工具过程交互重构 — 运行中默认展开、流式内容自动撑高度，整个回合彻底完成后才折叠；过程步骤（thinking / tool）运行中展开；消息头像与顶部状态旁增加运行三点指示。
  • 历史 / 记忆会话接力 — 存储中的历史会话详情页接入「接力给…」，复用同一份目标 Agent 选择菜单（本机 / 远程分组 + 模型选择）。
  • 多 CLI 附件支持 — Claude / Codex 等支持附件的 CLI 可在对话里粘贴、拖拽上传文件（SPEC-038）。
  • 浮层窄窗自适应 — Agent 选择等下拉浮层在窗口过窄时自动避让视口边界，不再被右侧裁切。

  • 远程工作区选择与节点引导流程优化（SPEC-032）。
  • 恢复 Windows / Linux 安装包的交叉打包与发布。

  • 会话消息顺序与标题改名的修复。

  • 会话真实标题（SPEC-035）。

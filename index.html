从选择运行环境到完成验收

会话和任务使用同一套 Runtime Host、CLI、模型与工作目录配置。任务可立即运行，也可按一次性计划或 Cron 执行；完成后进入 Review。

01 / RUNTIME

选择运行环境

选择本机或远程 Runtime Host，再指定 CLI、模型、工作目录与权限模式。

02 / CREATE

创建会话或任务

直接打开结构化会话或原生 CLI；需要跟踪交付时，从看板创建任务。

03 / RUN

立即或定时执行

任务支持立即运行、一次性计划和 Cron。对比工作台可向多个面板批量发送。

04 / REVIEW

检查结果并归档

任务完成后进入 Review，由用户确认 Done；历史会话可搜索并回到原上下文。
